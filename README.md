## 💻 How to Explore This Repository

**Option 1 — View online**

Open any `.ipynb` file from the repository to read the code, outputs, and explanations rendered by GitHub.

**Option 2 — Run locally**

1. Clone the repository:

   ```bash
   git clone https://github.com/QousainRaza/Prime-3.0-Apna-College-AI-ML.git
   ```

2. Open the project folder:

   ```bash
   cd Prime-3.0-Apna-College-AI-ML
   ```

3. Install Jupyter if needed:

   ```bash
   pip install notebook
   ```

4. Launch Jupyter:

   ```bash
   jupyter notebook
   ```

5. Open the notebook you want to explore.
